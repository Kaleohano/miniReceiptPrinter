# 今日小票

一个响应式的电子小票生成器。手机端和电脑端使用一致的照片选择流程；照片会经过红色复古打字机动画，生成包含时间、地点、天气和每日一句的可下载小票。

## 本地运行

请不要直接用 `file://` 打开，运行任意静态服务器：

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 说明

- 照片仅在浏览器内处理，不会上传到服务器。
- 用户同意定位后，页面通过 OpenStreetMap Nominatim 获取城市，通过 Open-Meteo 获取实时天气。
- 拒绝定位或网络不可用时，页面会使用文字降级，不影响小票生成。
