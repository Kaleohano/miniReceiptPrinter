# 今日小票

一个响应式的电子小票生成器。手机端提供宝丽莱翻转与后置相机取景，电脑端提供照片上传与拖放；两端都会生成包含时间、地点、天气和每日一句的可下载小票。

## 本地运行

摄像头 API 需要安全上下文，请不要直接用 `file://` 打开。运行任意静态服务器：

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 说明

- 照片仅在浏览器内处理，不会上传到服务器。
- 用户同意定位后，页面通过 OpenStreetMap Nominatim 获取城市，通过 Open-Meteo 获取实时天气。
- 拒绝相机、定位或网络不可用时，页面会提供相册上传和文字降级，不影响小票生成。
