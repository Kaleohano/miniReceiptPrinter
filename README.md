# 今日小票

一个响应式的电子小票生成器。手机端和电脑端使用一致的照片选择流程；浏览器会从照片中识别主体并制作白边贴纸，再经过红色复古打字机动画，生成包含时间、地点、天气和每日一句的可下载小票。

## 本地运行

安装依赖并构建网站：

```bash
npm install
npm run build
cd dist
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 说明

- 照片仅在浏览器内处理，不会上传到服务器。
- 第一次制作主体贴纸时会下载并缓存背景移除模型，之后可以直接复用。
- 主体识别失败时会自动使用原照片，不影响小票生成。
- 手机端保存会优先打开系统图片分享面板，可选择“存储图像”保存到相册；不支持文件分享时自动回退为下载。
- 用户同意定位后，页面通过 OpenStreetMap Nominatim 获取城市，通过 Open-Meteo 获取实时天气。
- 拒绝定位或网络不可用时，页面会使用文字降级，不影响小票生成。
